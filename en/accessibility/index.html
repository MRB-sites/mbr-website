Accessibility statement

Malmö Bygg & Riv AB is responsible for this website. We want as many people as possible to be able to use it.

How accessible is the website?

The website is built to meet WCAG 2.1 level AA: semantic HTML, keyboard navigation, visible focus, sufficient contrast, text alternatives and screen reader support.
